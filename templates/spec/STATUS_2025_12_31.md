### 🧪 Test-First Development (TDD)
**REQUIRED:** Red-Green-Refactor cycle for EVERY component/utility

1. **Write Tests FIRST** - Create `.test.tsx` or `.test.ts` before implementation
2. **Run & Fail (Red)** - Execute test, confirm failure
3. **Minimal Implementation (Green)** - Write minimum code to pass
4. **Refactor** - Clean up while keeping tests green
5. **Final Verification** - Run tests one last time

**Failure to follow TDD = INCOMPLETE WORK**

### 🎨 Styling Standards
**REQUIRED:** All visual elements from UNIFIED_LAYOUT_SPECIFICATION

- **Unified Layout ONLY** - No custom hex colors, ad-hoc font sizes, non-standard spacing
- **Tailwind Only** - Use utility classes, NO inline styles, NO custom CSS files (except animations)
- **Adaptive Design:**
  - ✅ Full Light and Dark mode support (MANDATORY)
  - ✅ Responsive: Mobile, Tablet, Desktop breakpoints

### ♿ Accessibility Standards
**REQUIRED:** WCAG 2.1 AA compliance

- **Keyboard Navigation** - All interactive elements accessible via Tab + Enter/Space
- **Visual Focus** - Focus states clearly visible
- **Semantic HTML** - `<article>`, `<nav>`, `<aside>` instead of generic `<div>`
